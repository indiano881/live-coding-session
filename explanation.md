💻 Live Coding Session – JavaScript String Manipulation
Starting point
Given the following string:
const sentence = "My name is Davide and I am from Italy";


Complete the following challenges using JavaScript.
Challenge 1 – Filter words 🟢
Return only the words longer than three characters.

Expected output:
["name", "Davide", "from", "Italy"]


Challenge 2 – Reverse the string 🟡
Reverse the entire string, character by character.

Expected output:
"ylatI morf ma I dna edivaD si eman yM"


Challenge 3 – Find the most frequent letter 🔴
Find the most frequently occurring letter in the string.

Requirements:
- Ignore spaces.
- Ignore uppercase and lowercase differences.
- Return the letter and its number of occurrences.
Expected output:
"a": 5
